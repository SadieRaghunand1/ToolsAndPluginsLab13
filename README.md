Lab project created over the course of a week for the course DIG 4778C - Game Design Tools and Plugins
Used API for a weather program that collects data for current weather conditions at coordinates internationally.  
Tasks were to pull data from this database using the API and create a Unity scene that uses this data to reflect the weather conditions of a specified coordinate.
The skybox will change based on the time of day recorded at the coordinate and the weather at the coordinate using free skybox assets from the Unity Asset Store
